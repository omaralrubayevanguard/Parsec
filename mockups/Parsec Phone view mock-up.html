Phone viewA look, not working — pick A or B.

  • One file, one set of dataThe phone view is a layout of the same Parsec, not a second app. Same pages, same buttons, same rules — only the arrangement changes.
  • SwitchYour initials › Appearance › Screen: Automatic, Computer or Phone. Saved per device, so the shop PC stays the computer view.
  • Every pageLists stay lists; tap a row to open it full screen. Side panels become sheets from the bottom. Tables become rows. Charts go full width. Tabs inside a page scroll sideways.
  • A or BA: your four pages in a bar at the bottom, the rest under More. B: a menu button (☰) top left that slides out the same side menu as the computer — more room for the page.
  • The dataOne file on one web address gives one place to open it. The data is shared only once your database is in. Until then a phone keeps its own copy (phones can’t open the shop folder) and QR sync carries a technician’s work.
