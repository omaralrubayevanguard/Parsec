Parsec 14 — code review
Read-only pass over the built file (Parsec_14.html, 7.96 MB) and what builds it (build12.py, b9/*.js, b9/*.css, b9/build_*.py, b8/clean.py, the Parsec_8.html base). Counts come from scripts over the file; "confirmed" means reproduced in the browser or traced in the code, "likely" means a strong read of the code without a reproduction.


Fix first — the top 20
 1. HIGH · M · build: the app is 3 MB of base (Parsec_8.html, 42,630 lines) plus 30 patch files that search-and-replace strings in it. 41 functions are cut out and replaced whole (raNext, setRoStatus ×2, opCompleteGaps, usd, staffList, tgPopHtml ×2 …). Two patches already silently skip ("build_v130b: skipped (already changed elsewhere): pxSecYou PIN, pxSecSign PIN note"). One more edit to a replaced function and the next build breaks or, worse, half-applies. Do this: move the replaced functions into b9 files and delete them from the base; make skipped patches fail the build.
 2. HIGH · S · b9/imp1.js is generated (_p132x.py from imp1.js.131 + x132/*). A hand edit to imp1.js is lost the next time anyone runs _p132x.py. Do this: delete the generator and keep imp1.js as the one source, or the other way round — never both.

HIGH · M · Full re-render every 5 s while any clock runs (beat(): "period = runningPunches().length ? 5000 : 60000; … render()"), on top of four 1-second tickers (TK fields, tickTimers, the sign-in clock every 2 s, lgEodCheck every 20 s, watchFolder every 5 s, scanFolder). A tech on the clock all day means ~6,000 full page rebuilds. Likely: typing that spans a redraw is only protected by safeToRedraw(). Do this: tick the clocks in place (the TK mechanism already exists) and render only on data change.
 4. HIGH · S · Google Fonts is still requested at every load (Poppins, IBM Plex Mono) and the shop's data file is a work computer behind IT rules. Confirmed: the only outside request at load. Do this: drop the link (Geist/Newsreader are embedded already; Poppins/Plex are not used on any page) — 0 outside requests.

1 · Bugs and errors
 · Confirmed: #assist-root (the hidden Assistant: a floating button, a chat panel, Settings text about a key at console.anthropic.com) is created on every load by initAssistant(); fork B removed the network call, not the panel. 33 KB of code, 34 DOM nodes, and a "window.__asstDebug" global.
 · Confirmed: outside request at load — fonts.googleapis.com (Poppins, IBM Plex Mono). Neither family is used by any rule that applies (pages use Geist, Geist Mono, Newsreader — all embedded).
 · Confirmed: viewROs has "var openN … doneN" declared twice in one function (base, lines 15773/15776 of the app script). Later one wins; both compute the same thing.
 · Confirmed: full render on a timer — beat() every second decides: a running punch → render() every 5 s, otherwise every 60 s; plus setInterval ticks at 1 s (TK fields), 1 s (tickTimers), 2 s (sign-in clock + idle check), 5 s (watchFolder), 20 s (EOD check), and scanFolder. Listener and DOM counts stay flat across renders (150 document / 42 window listeners before and after 39 page renders; 1,002 nodes stable) — so no leak, but a lot of work.
 · Confirmed: no console errors on any of the 13 pages in Ivory or Graphite, nor on the RO page; focus rings are visible on all 25 tabbed controls on Triage.
 · Likely: 500 empty catch(e){} of 778 — including around persist/scheduleSave/folder writes; a failed save is silent. 144 "typeof X === 'function'" guards: patches testing whether another patch is present — a missing function silently turns a feature off instead of failing loudly.
 · Likely: "==" 618 times (340 "== null", 278 other) next to 9,704 "===" — the 278 are mostly numeric/string ids from data attributes; harmless, but pick one.
 · Likely: two days are taken from toISOString().slice(0,10) (UTC) — a sample ETA (line 17137) and the exported sheet's file name (30354); every other day uses localDay(). Fine in Greensboro before 7 pm.
 · Status strings: 0 comparisons against the wrong case (good — pgStKey normalises). Statuses are still compared as free strings ("Waiting – Parts" with an en dash) in ~400 places; one typo with a hyphen would silently miss. A STATUS enum would catch it.
 · The pruner (b8/clean.py js_unreferenced) only removes column-0 functions whose name appears nowhere else in the file as a word — a name in a comment or a string keeps the function. It removed 268 functions this build; dead functions mentioned in comments stay.
