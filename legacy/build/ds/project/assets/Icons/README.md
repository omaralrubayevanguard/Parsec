# Icons

Parsec's stroke set: 24px grid, 1.6 stroke, round caps and joins, no fill. The files are drawn in #857F75 (`status-hold`, Ivory) so they read on light and dark tiles; in the product inline the SVG and set `stroke` to `currentColor`, at 16px, in `ink-3` at rest and `ink` when active.

Copied from the app's own set (console, ros, foreman, manager, triage, timelog, parts, career, warranty, fixes, gear, bell, search, play, stop, swap, print, trash, clock, keyTag, history and the rest). `chevD`, `chevU`, `chevR`, `more`, `inbox`, `sidebar` and `link` are intentional additions for the new shell, and `today`, `camera`, `mic`, `sync` and `chevL` for Parsec Mobile's tab bar and action bar — all drawn to the same rules.
